# 龙鳞（LoongScales）产品简介

> 龙鳞是一款运行在浏览器里的**分层图片编辑器**，操作体验接近 Photoshop / Photopea，并深度整合了 **AI 生图 / 去背景 / 拆图** 能力与 **龙骨动画（LoongBones）素材同步** 能力。
> 本文档面向设计师与动画师，按照"先认识、再上手、后精通"的顺序，教你从零用好这款工具。

## 龙鳞是什么

龙鳞是一个**纯网页的 2D 分层图像编辑器**。你不需要安装任何软件，打开浏览器即可使用；你的作品自动保存在本地，关掉网页也不会丢失。

它既能像 Photoshop 一样画画、调色、做图层、加特效，又额外提供三类"AI 加持"的能力：

- **AI 生图**：用一句话描述，直接生成图片（文生图），或基于现有图层改造（图生图）。
- **AI 去背景 / 拆图**：一键把图片背景去掉，或把一张合图拆成多个独立图层。

## 它在龙骨动画工具链中的位置

| 工具 | 角色 | 与龙鳞的关系 |
|---|---|---|
| **龙骨动画（LoongBones）** | 2D 骨骼动画创作平台（类似 Spine， live2D） | 负责绑骨骼、做动画 |
| **龙鳞（LoongScales）** | 原画 / 素材精修编辑器 | 负责画原画、拆分图层、改皮肤、做 AI 生成 |

龙骨动画的一个角色通常由很多张"素材图"拼成（身体、手臂、头发……），每一张素材对应龙鳞里的**一个位图图层**。龙鳞与龙骨之间可以**双向同步**：

- 从龙骨把素材**拉**进龙鳞 → 精细绘制 / AI 改造；
- 在龙鳞画好后**推**回龙骨 → 立刻变成动画素材。

这样，**原画设计 → 图层拆分 → 改皮肤 → 骨骼动画** 整条 2D 动画生产线就在同一套工具里打通了，而且**每一步都能用 AI 辅助**。

## 核心能力一览

- 真实的图层系统：位图、文字、矢量、调整图层、填充图层、组
- 27 种图层混合模式、16 种调整、6 种滤镜、15 种图层特效（全部非破坏性）
- 完整的绘画工具：画笔、橡皮、喷枪、涂抹、仿章、减淡、加深……
- 选区、图层蒙版、剪贴蒙版、对称绘制、渐变、形状、钢笔路径
- 支持导入 / 导出 **PSD**
- 内置 **AI 生图 / 去背景 / 拆图**与**龙骨素材同步**
