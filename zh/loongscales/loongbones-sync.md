# 与龙骨动画协同

这是龙鳞最独特的价值：**它是龙骨动画素材的精修与拆分工作站**。

## 核心概念

- 龙骨素材库里的一张图 = 龙鳞里的**一个位图图层**（同步单元）。
- 绑定关系通过一个关联键 `loongbonesId` 维护：一旦图层绑定，图层面板显示蓝色链接图标，且**受保护（不可删、不可向下合并）**。
- 同步只处理**位图图层**；文字/矢量/调整/填充/组不参与。

## 从龙骨拉取素材（龙骨 → 龙鳞）

在宿主（龙骨）里点"用龙鳞编辑素材"，龙鳞会：

1. 把龙骨素材库里的位图（含纹理集合图）拉进来，每张建成一个带绑定关系的位图图层；
2. 你就能在龙鳞里逐张精修、AI 改造。

> 若龙骨里某素材在龙鳞侧已不存在，同步拉取时会询问你是否删除龙鳞对应图层（默认保留，确认才删）。

## 同步到龙骨（龙鳞 → 龙骨）

画好后点顶部/宿主的 **"同步到龙骨"**（推）按钮，龙鳞会：

1. 收集**已绑定**且**内容有改动**的位图图层；
2. 只裁剪"有像素的区域"上传（节省体积），并把结果写回龙骨素材库（按关联键幂等更新）；
3. **不会删除**龙骨里已有的素材 —— 你在龙鳞删了图层，不会反向删龙骨资源（避免破坏动画骨骼引用）。
4. 第一次同步时，会自动在龙骨舞台上创建对应的 slot（插槽），把每个位图图层摆到舞台上，立刻可用于绑骨骼、做动画。
5. 再次同步时，只会更新已绑定素材，不会创建新 slot。

### 首次推送 vs 后续推送（文档、舞台与草稿箱）

把龙鳞作品**第一次** vs **第二次及之后**同步到龙骨时，行为不同，理解它能避免困惑：

- **第一次从龙鳞同步到龙骨**：
  - 会以**与龙鳞相同的 `workId`** 在龙骨侧创建一个对应的龙骨文档（两者一一对应）；
  - 同时**自动在龙骨舞台（Stage）上创建对应的 slot（插槽）**，把每个位图图层摆到舞台上，立刻可用于绑骨骼、做动画。
- **第二次及之后的同步到龙骨**：
  - 文档与已有 slot 已存在，龙鳞主要做内容更新；
  - 若龙鳞这边**新增了图层**（龙骨之前没有对应素材），这些新图片**不会自动创建 slot**，而是被放进龙骨素材库的 **草稿箱**；
  - 你需要**手动从草稿箱把新素材添加到素材库**后，才能在动画里使用。

> 一句话：首次同步"建工程 + 摆上舞台"；后续同步里纯粹的"新素材"只进草稿箱，要不要上舞台由你决定，避免自动摆位打乱已有动画绑定。


## 纹理集与一键拆图

龙骨的**纹理集（Sprite Sheet）**是一张大合图 + 一份子块描述。龙鳞的对应策略：

- 合图整体作为一个位图图层导入，并标记"这是纹理集"（紫色网格图标 🔲）。
- 点图层上的 **「一键拆图」**，会按子块矩形把合图切出为多个独立位图子图层（各自绑定回龙骨子块），原合图图层隐藏保留。
- 你精修某个子图层后，同步时会把改动写回合图对应区域再整体上传。

## 受保护图层与删除策略（务必理解）

| 方向 | 行为 |
|---|---|
| 龙鳞删图层 → 龙骨 | **不删**龙骨素材（保守，防误伤动画） |
| 龙骨删素材 → 龙鳞 | 拉同步时**可删**龙鳞对应图层（需你确认） |
| 手动删/合并绑定图层 | **禁止**（蓝色链接图标，按钮置灰） |
