# 快捷键速查表

| 功能 | 快捷键 |
|---|---|
| 撤销 / 重做 | `Ctrl+Z` / `Ctrl+Y`（或 `Ctrl+Shift+Z`） |
| 自由变换 | `Ctrl+T` |
| 切换剪贴蒙版 | `Ctrl+Alt+G` |
| 全选 / 取消选择 / 反选 | `Ctrl+A` / `Ctrl+D` / `Ctrl+Shift+I` |
| 剪切 / 复制 / 粘贴 | `Ctrl+X` / `Ctrl+C` / `Ctrl+V` |
| 粘贴为新图层 / 贴到原位 | `Shift+V` / `Alt+V` |
| 交换 / 重置前景背景色 | `X` / `D` |
| 唤起/收起 AI 面板 | `Ctrl+K` |
| 临时抓手平移 | 按住 `空格` 拖动 |
| 删除图层 / 清除选区像素 | `Delete` / `Backspace` |
| 微移图层（步长 10） | 方向键（按住 `Shift`） |
| 应用/取消（裁剪·变换·变形·钢笔） | `Enter` 应用 / `Esc` 取消 |
